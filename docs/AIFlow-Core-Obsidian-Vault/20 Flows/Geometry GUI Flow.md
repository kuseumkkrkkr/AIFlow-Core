# 기하 GUI 입력 플로우

기하 탭은 WolframAlpha식 자연어·키워드 질의를 사용하지 않는다. 사용자가 좌표 평면을 눌러 만든 점과 드롭다운에서 정한 순서를 구조화 JSON으로 보낸다. 그러므로 `AB·CD`에서 어느 두 점이 한 벡터인지, 두 직선의 순서가 무엇인지가 화면 입력 그대로 보존된다.

```mermaid
flowchart LR
    A[좌표 평면 클릭·좌표 수정] --> B[점 A..L JSON]
    B --> C[연산 및 점 순서 선택]
    C --> D[/api/geometry UTF-8]
    D --> E[점 ID·개수·유한 좌표 검증]
    E --> F[거리·중점·넓이·내적·교점 계산]
    F --> G[연산별 독립 불변식 검산]
    G --> H[PASS 또는 FAIL JSON]
```

## 현재 연산과 검산

| 연산 | 입력 순서 | 독립 검산 |
| --- | --- | --- |
| 거리 | A, B | `AB²=(Δx)²+(Δy)²` |
| 중점 | A, B | `2M=A+B` |
| 삼각형 넓이 | A, B, C | 신발끈식의 두 배 넓이 |
| 벡터 내적 | A, B, C, D | `AB·CD` 성분곱 합 |
| 직선 교점 | A, B, C, D | 교점을 두 직선 외적식에 재대입 |

평행·일치 직선, 일직선 위의 세 점, 퇴화 벡터, 존재하지 않는 점은 임의 답 없이 `FAIL`로 반환한다.
